# Phase Lag Audio

Phase Lag 运行时只使用已导入的正式音频：

- `music/tragic_ambient_main_menu.ogg`：主菜单。
- `music/life_in_corrupted_binary.ogg`：第一、二、五章解谜。
- `music/menacing_otherworld.mp3`：第三章冷区。
- `music/open_warfare.mp3`：第四章和 Boss 战斗。
- `ambience/factory.ogg`：设施环境底噪。
- `sfx/*.ogg`：UI、实体管线、脚步、挥砍、闪避、寄生体、无人机、门、激光、护盾、终端、碰撞和爆炸反馈。

作者、许可证、原文件名、裁切/转码内容和下载来源见 [`docs/phase-lag-asset-sources.md`](../../../docs/phase-lag-asset-sources.md)。
