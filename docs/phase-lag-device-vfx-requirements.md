# 《迟相 / Phase Lag》机关、道具与 VFX 需求

## 设计原则

机关必须先像真实设施，再像谜题组件。玩家应从外形、端口、运动方向、场景连线和声音理解功能；字符芯片、白色几何条、巨型准星、手绘霓虹装饰层和与背景脱离的墙板界面都不能作为正式视觉。

所有可交互对象必须处于玩家实际可到达的通道内。需要站立操作的核心交互点应接近角色胸口或手部高度；高处设施只能作为被远端驱动的输出，不能要求玩家接触一个碰不到的按钮。

## 通用状态

| 状态 | 视觉要求 |
| --- | --- |
| idle movable | 常驻弱描边，足以从背景读出但不发光。 |
| player near | 描边提高一档，并出现短交互提示。 |
| focused/hover | 轮廓稳定，不出现大准星或扫光。 |
| held | 角色手边显示真实道具纹理、端口和当前 `0/90/180/270°` 朝向。 |
| valid socket | 插槽边缘和匹配端口同时亮起；不只改变一个小状态灯。 |
| invalid socket | 短促拒绝抖动/声音，随后恢复；不能吞掉道具或静默失败。 |
| local active | 设备立即产生机械运动和本地状态。 |
| remote in flight | 只在发送源和目标连线/目标局部保留低强度提示。 |
| remote arrival | 目标轮廓、像素块和机械动作在真实抵达时同步发生。 |
| reset | 清楚逆转到稳定初态，并清空在途提示。 |

描边建议在最终显示尺度保持约 `1–2px` 弱态、`3–4px` 近距离/手持态；颜色只辅助，外形和动作必须独立可读。`low_flash_mode` 将快速闪断改为较长的稳定轮廓与低频脉冲。

## 方向与端口语义

- 直通模块横放时连接左/右端口，竖放时连接上/下端口。
- 弯头的两条可见导管必须与实际输入/输出方向一致。
- 分路器必须清楚显示一个输入和两个输出，不能用普通直线贴图加文字说明。
- 反相盒必须用机械翻转、常闭/常开触点或双色双态结构表达，不只显示 `NOT` 字符。
- 联锁盒必须让两个独立输入在实体结构上汇合，不能只显示 `AND` 字符。
- 保持锁必须具有能看见的棘爪、锁舌或机械保持件；触发后维持姿态。
- 所有旋转以顺时针 `90°` 为一步，贴图、HeldPreview、端口判定和管线高亮必须同步。

## 道具差异

| 道具 | 必须读出的特征 | 禁止替代 |
| --- | --- | --- |
| 电池 | 明确的储能罐/电芯、正负或机械极性、可抓握结构 | 白色长条、保险丝换色版 |
| 保险丝 | 细长保护件、透明/陶瓷壳、熔断结构 | 缩小电池、字符 `FUSE` |
| 配重 | 高密度金属块、把手、明显重量感 | 普通箱子、发光球 |
| 1/3/6s 继电器 | 同一族外壳，不同数量的机械延迟单元 | 仅靠数字文字区分 |
| 反相盒 | 常闭/常开触点或翻转拨片 | 字符 `NOT` |
| 联锁盒 | 两输入汇流到一个输出 | 字符 `AND` |
| 保持锁 | 棘爪/锁舌保持已触发位置 | 字符 `MEM` |
| 三格蓄能器 | 三个独立实体格，每次抵达点亮并锁住一格 | 三条纯白矩形 |

## 机关合同

- **门**：过去侧和未来侧共享同一门框坐标，但使用不同年代的完整门体素材。未来侧是冷色加固门；过去侧是旧式门。禁止在原门上叠加随意绘制的护栏、裂纹 Polygon、霓虹边或烧焦贴纸。
- **压力板**：必须有可见下沉行程、受力面和朝向；残骸压住后保持机械下沉，不靠 HUD 写“已触发”。
- **升降平台**：运动前有短机械预备，停止时有落锁；平台本体与碰撞同步，不能先飞走贴图再移动碰撞。
- **护盾**：发生器与屏障分开；关闭时是能量逐步失稳，不是整屏白闪。
- **激光**：发射器、光束路径和危险区一致；启动预警必须给过去侧留下可反应时间。
- **断路器/总闸**：有明确上下稳定位置，玩家拉闸后手柄、状态灯和真实输出同时更新。
- **远端接收器**：发送和抵达使用成对的形状/声音动机；接收器不能被误认成可搬运道具。

## 两个时代的同地点表达

- 相同坐标保留同一门框、主导管、立柱、窗和大型机器轮廓。
- 未来侧通过加固件、修补焊缝、冷色材料和老化设备表达事故之后。
- 过去侧通过原始结构、事故警报、局部烧蚀和暖色照明表达事故当时。
- 年代差异必须来自完整素材与材质处理，不来自临时手绘装饰层。
- Ch1 R1 两扇门必须一眼看出年代不同，同时仍能认出是同一坐标的同一类门。

## VFX 节拍

- 本地操作反馈在输入后 `100ms` 内出现。
- 拿取、放置、旋转使用 `0.12–0.22s` 的小范围机械反馈。
- 远端抵达使用对象局部 `0.24–0.42s` 的轮廓/像素块收束；不能遮住玩家或手持物。
- 敌人预警先由本体动作建立，再由小范围轮廓或地面标记辅助。
- Boss 可以更夸张，但每阶段只保留一个主视觉事件：拆甲、磁夹或核心开启。
- 失败/复位不使用死亡式全屏爆闪；清空在途结果后直接恢复稳定场景状态。

## 制作与接入验收

- [ ] 每个可搬运物缩成纯黑剪影仍能区分。
- [ ] 直通、弯头、分路、反相、联锁和锁存的可见端口与真实逻辑一致。
- [ ] 所有必须由玩家操作的机关都处于可接触范围。
- [ ] 手持预览不会被选中框、文字或角色身体遮住。
- [ ] 两侧同坐标地标一致，年代差异不依赖随意叠加装饰。
- [ ] 在 `1280×720` 的 `1:1` 分屏下仍能读出道具、朝向、插槽和抵达状态。
- [ ] VFX 不改变碰撞、端口、机关计时或完成条件。
