# 《回声追猎 / Echo Chase》Jam 设计文档

> 工作标题,暂定。GodotHub Jam,主题「延迟 / Delay」。截止 2026-09-03。
> 本文档取代旧的 `phase-lag-*` 系列。旧的双角色跨时空解谜规范作废,不再作为约束。

## 一句话核心

你的过去会追上你——追杀者精确重演你 N 秒前走过的每一步;你要在被自己的过去抓到之前到达出口,同时利用这个"过去的自己"去触发你一个人做不到的事。

主题契合:延迟 = 你的行动延迟 N 秒后由回声重演。不是输入延迟,是「你做过的事,过一会儿才回来找你」。

## 核心循环(锁定)

```text
进入房间
  -> 移动/跳跃,系统记录你的完整轨迹
  -> N 秒后,追杀者从你的起点出发,精确复现你的每一步
  -> 在被追上之前:到达出口 / 撑到计时结束
  -> 被追上 = 本关失败,立即重来
```

## 追杀者规则(命门,不可违反)

这套规则解决"追杀者会不会死、能不能帮你踩陷阱"的全部逻辑矛盾。任何新机关都必须服从它。

- **追杀者是回声,不是实体。** 它精确重演玩家 N 秒前的轨迹(位置 + 动作),不能做任何玩家没做过的事。
- **它对陷阱完全免疫。** 它不会死,不会被尖刺/激光影响。理由:让它会死就产生悖论(它踩过的点你必然先踩过),且"杀死它"会让关卡直接失效。
- **它唯一能伤害的是现在的玩家。** 碰到玩家 = 本关失败。
- **它唯一能影响世界的方式是「重量 / 存在」**:踩压力板、挡光、压开关。它不能拾取、不能攻击、不能操作需要主动意图的东西。

由此推出一条铁律:**「追杀者帮你清掉陷阱」这种机关不存在**,因为它对陷阱免疫,而且你必然先于它踩到同一个点。不要再设计这类机关。

## 两条互不干扰的难度线

| 线 | 作用对象 | 本质 |
| --- | --- | --- |
| 陷阱层 | 只威胁「现在的玩家」 | 纯跑酷障碍:尖刺、激光、塌陷、移动平台 |
| 追杀者层 | 只威胁「现在的玩家」,只以重量影响世界 | 时间压力 + 偶尔的工具 |

两条线不交互。陷阱不影响追杀者,追杀者不清陷阱。玩家要同时应付「脚下的跑酷」和「身后的过去」。

## 核心原语:过去的自己 = 时机工具

完美复现下,追杀者不能做任何你没做过的事。它作为工具的**唯一价值是时机**:它能在更晚的时刻,出现在你早已离开的位置。

所有"解密"机关都从这一条派生,而不是从"它有新能力"派生:

- **远程压力板门**:门只在有人踩板时开,板离门远。一个人做不到(踩了板就到不了门)。解法:踩板 -> 跑向门 -> N 秒后追杀者替你再踩板 -> 你算好正好在那一刻到门口穿过。
- **双板同步**:两块相距很远的板必须同时被压。你踩 A、跑到 B,算好追杀者抵达 A 的时刻你正踩着 B。
- **计时出口**:出口只在追杀者压到某个点后的几秒内开启,逼你精确站位。

核心张力:**你希望追杀者离你近(好利用它的时机),又不能太近(会被抓到)**。威胁和工具是同一个东西。

## A 基调:动作跑酷优先

起步做成短、快、紧张的跑酷关,追杀者主要是威胁,机关是点缀。后面几关再慢慢渗入时机编排的解密。理由:动作跑酷是已验证能做出来、也好调的(见 GMTK `Last Minute Echo` 的经验);解密编排容易做砸,放后面。

### 关卡教学顺序(MVP,先做这 5 关)

| 关 | 教什么 | 只引入 |
| --- | --- | --- |
| L1 直线逃 | 追杀者是什么、会重演你、会抓死你 | 出口、追杀者 |
| L2 拐弯 | 你的路会绕回来,别把自己逼进死角 | 简单地形 |
| L3 陷阱 | 陷阱只威胁你,追杀者免疫 | 尖刺/激光 |
| L4 远程板 | 过去的自己能替你踩板(时机工具) | 压力板 + 门 |
| L5 收束 | 综合跑酷 + 一次时机编排 | 组合已有 |

先把 L1 一个房间做到「自己玩着觉得追逐手感对了」,再往下扩。不要先铺 5 关再调手感。

## 36 天范围切分

- **第 1 阶段(约 1 周)**:只做 L1。追杀者轨迹记录 + 重演 + 抓死判定 + 重开。调到自己玩着紧张、好玩为止。这是整个游戏的地基,不好玩就别往下做。
- **第 2 阶段(约 1 周)**:L2、L3。加地形和陷阱层。验证「跑酷 + 逃过去」两件事叠在一起还成立。
- **第 3 阶段(约 1 周)**:L4、L5。加压力板时机工具。这是第一次出现"解密",最容易做砸,留足时间。
- **第 4 阶段(约 1 周)**:从下面「扩展菜单」选 1-2 个已验证好玩的方向扩,加音效/美术占位素材,做 itch 页面,提交。

## 待验证扩展菜单(醒来挑,别全做)

你担心可玩性单薄,是对的。下面这些都和「回声 = 完美重演的幽灵」这条规则兼容,不会重新掉进陷阱悖论。**每个都先做一个房间验证好玩再纳入,不好玩就砍。**

1. **多重回声(最强扩展)**:每跑完一圈 / 每按一次装置,就多叠一个更早路径的回声,不同 N 各自追你。既是难度倍增器,也让「多块板同时压」这类谜题成立(你 + 多个过去的自己)。这是可玩性天花板最高的一个方向。
2. **可变 N 作为资源**:某些区域 / 拾取物改变回声的延迟。缩短 N = 更危险,但可能是让回声更早踩到板的唯一办法。既是难度旋钮又是解谜资源。
3. **可控回声起点(找回主动性)**:一个装置能把你当前位置「录」成一个新回声的起点。让玩家有限地决定「过去的自己从哪开始」,在不破坏重演逻辑的前提下把主动权还给玩家——正好回应你说的「只能被动控制」。
4. **回声挡光/挡投射**:回声的「存在」能挡住激光或投射物,你把它的路线用作移动掩体。仍受限于「它只会重走你走过的路」。
5. **追逐高潮关**:一条长关卡,N 持续缩短,纯逃亡,作为章节收尾的爽点。
6. **轻剧情 / meta 层(可选,最后)**:「被自己的过去追赶」自带 meta 味,关卡间加极少量文字即可,不做独立剧情系统。jam 阶段能不做就不做。

优先级建议:先验 1(多重回声)和 2(可变 N),这两个能用最小改动把可玩性翻几倍。3 留给「想要主动性」时再上。

## 明确砍掉

- 「追杀者帮你踩掉/触发陷阱」——逻辑不成立。
- 追杀者可被杀死 / 会死亡。
- 旧 phase-lag 的双角色、跨时空分屏、实体管线维护焦点、五章结构、Boss 三阶段。
- 一切在核心循环好玩之前就铺开的剧情、章节、美术定稿。

## 防坑规则(来自你自己的教训)

- **先做一个房间调到好玩,再扩。** GMTK 的教训:先铺大结构再调手感 = 做砸。
- **核心循环的代码你自己写或至少能完整读懂改动。** 07-26 的觉悟:进入游戏这座山时,本人必须在制作过程里,且有自主修改权。追杀者的记录/重演/判定是这个游戏的心脏,别整段交给 AI 抽卡。
- **AI 只在你定好灰盒和规则后,做明确的实现任务**(写重演算法、判定、生成占位关卡),不要「从骨架到血肉一次性生成」。
- **不好玩就砍,不要为了保留改动而交付玩不动的东西。**
