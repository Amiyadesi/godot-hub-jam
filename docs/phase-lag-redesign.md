# 《迟相 / Phase Lag》关卡与剧情合同

## 核心表达

《迟相》的核心不是输入延迟，而是“一个空间已经发生的结果，要在另一段时间之后才成为事实”。玩家要观察、预演并利用这段等待，而不是和操作手感对抗。

- 陆衡位于未来的冷色加固设施。
- 星遥位于过去的暖色事故设施。
- Ch1–Ch2 只暗示“两座设施被同步”。
- Ch3 确认两人位于同一地点的不同时代。
- 相位猎手制造了过去事故，并故意让两条时间线相互咬合。
- Boss 的死亡属于既定历史，不产生分支时间线。

## 五章结构

| 章节 | 流程 | 禁止内容 |
| --- | --- | --- |
| Ch1 | 三个解谜教学房。 | 不提前解释同一地点/不同时代。 |
| Ch2 | 三个双人因果协作房，始终 `1:1` 分屏。 | 不用分屏面积表达角色占比。 |
| Ch3 | 三个综合延迟房，星遥承担更多执行段。 | 不再引入新的抽象按键或网格规则。 |
| Ch4 | 纯相位猎手 Boss 战。 | 无前室、普通房或可玩教程段。 |
| Ch5 | 纯结尾演出。 | 无玩家关卡、谜题、战斗、门或失败状态。 |

Ch4 可在 Boss 场内播放约 `10–15s` 的不可操作入场对白。Ch5 由 Dialogue Manager、AnimationPlayer、镜头和音频推进。

## 输入与可读性

### 陆衡

- 管线外 `J`：优先放下手持磁力道具；靠近总闸时只进入实体维护焦点；否则使用近距离检修设备。
- 焦点内方向输入：沿真实导管选择插槽或总闸，不按屏幕距离跳选。
- 焦点内 `J`：插拔当前模块或拉闸；`K`：旋转手持模块或当前可旋转模块；`L`：退出焦点并保留手持模块。
- 焦点外 `K`：旋转直接手持的磁力道具；焦点外 `L`：地面闪避。
- 实体维护焦点仍处于世界中，不切换到 modal、独立镜头或格子光标；陆衡暂时停止移动，角色和设备继续可见。

### 星遥

- `J`：快斩和连段。
- `K`：蓄力破甲或精确反击。
- `L`：地面/空中冲刺。

### 单人和双人

- `solo`：P1 使用 `Q` 在固定角色之间切换。
- 单人任一角色离场后自动切到另一角色，并锁定本房间剩余时间内的 `Q`；下一房间或明确复位时解除。
- `local_coop`：P1 固定陆衡，P2 固定星遥。
- 新游戏先选模式；继续游戏读取存档模式。
- 局内禁止热加入和模式切换。
- 未操控角色自动防御普通攻击；破防攻击只保留预警，不能直接惩罚当前无法控制的一侧。

## 实体因果管线

旧网格墙板已经删除。关卡中的插槽、导管、闸刀、输出和设备都属于真实空间：玩家能看见它们与门、平台、护盾或机关之间的连接。

- 本地输出即时响应。
- 跨时空输出默认延迟 `3s`。
- 实体延迟模块额外增加 `1s`、`3s` 或 `6s`。
- 弱青色描边表示可拿取模块；合法插槽使用绿色，非法目标使用低亮橙色，fixed 插槽作为暖灰拓扑地标。
- 总闸入口约 `220px`，磁力物体约 `190px`，普通机关约 `180px`；只有总闸进入实体维护焦点。
- 电池、保险丝、配重、继电器、反相盒、联锁盒、保持锁和蓄能器必须使用不同外形。
- 错误解法通过局部机关或房间复位恢复，不以死亡惩罚试错。

## 九房教学与复位节拍

每个房间都先让场景说话，再用 radio bark 补规则。提示不会一次给出完整插槽答案；房间只在玩家已经观察过机制、停滞或复位后逐级增加信息。

### Ch1 R1：断线

- **视觉锚点**：同坐标的两扇门保留相同骨架，但未来侧是完整冷色门和实体管线，过去侧是暖色旧门、烧毁控制器与断开的同位置导管。
- **首次观察**：玩家靠近总闸按 `J` 进入维护焦点，用 `WASD` 沿导管选中橙色断点旁的模块，`J` 拿取、`K` 旋转、`J` 放回；总闸在整条线路成立前保持机械拒绝状态。
- **单人切换窗口**：陆衡侧总闸前与星遥侧烧毁控制器前都是安全地面；本地门开启后保持锁存，玩家无需抢时间切换。
- **复位反馈**：模块回到各自托架，总闸弹回，未来导管逐段熄灭，在途轨迹收回；两扇门保持明确的关闭姿态，不伤害玩家。
- **提示层级**：先显示可旋转模块的真实端口；停滞后提示“横接左右、竖接上下”；第二次错误复位后才让正确连通的导管段逐段保持亮起。

### Ch1 R2：余波

- **视觉锚点**：无人机保持横向悬浮轮廓，寄生体贴地收缩；未来侧两个对应体分别被门段隔开，避免同时压迫陆衡。
- **首次观察**：星遥先在安全距离看到无人机压低机头的俯冲预警，再看到寄生体收紧外壳的跳扑预警；第一次攻击只教学一种反应。
- **单人切换窗口**：每个敌人死亡后到下一段门开启前留出稳定平台，未来侧对应体在延迟抵达前只执行可防御的普通攻击。
- **复位反馈**：仅重置当前敌人段；敌人回到出生点并播放短暂重组，未来侧在途死亡轨迹被清除，已完成的前一段不回退。
- **提示层级**：先靠动作预警；受击一次后给出“俯冲先让开 / 跳扑先等它落地”的人物反应；重复失败才显示短暂的攻击有效时机描边。

### Ch1 R3：检修

- **视觉锚点**：左区电池座与检修升降台、中区高处保险丝、右区电池/保险丝插槽、固定 AND、可旋转 `wire_tee`、总闸和两路真实导管组成一条可追踪因果链；最终操作区横向展开约 `560px`。
- **首次观察**：电池先让升降台到达高处；取得保险丝后回到地面并取回电池。两件道具分别点亮 AND 的两个输入，初始错误方向的 `wire_tee` 只需一次 `K` 旋转即可同时连通本地与远端输出。
- **单人切换窗口**：本地服务门即时开启并锁存，过去侧气闸约 `3s` 后开启并锁存；完成供能后可安全切到星遥处理寄生体与无人机。
- **复位反馈**：错误旋转只在首个断点显示短促橙色反馈，不吞道具；整房复位恢复升降台、插槽、三通、总闸和两扇门，并清空尚未抵达的开门事件。
- **提示层级**：开场只说明升降台、保护回路与气闸失去供能。进一步提示只能从暂停菜单主动请求，内容给因果线索，不自动弹出步骤或完整答案。

### Ch2 R1：分路

- **视觉锚点**：未来侧分路器的向下支路直接连到升降台轨道，穿墙支路与过去侧护盾门框处于相同坐标；两侧始终 `1:1` 分屏。
- **首次观察**：接通一条本地支路即可无危险地看到升降台即时移动；护盾侧保留足够空地观察远端结果稍后抵达。
- **单人切换窗口**：升降台到位后停住，护盾关闭后也维持稳定，两个移动验证之间都允许在安全平台切换角色。
- **复位反馈**：升降台缓慢回到底部，护盾重新合拢，分路器两支路按各自方向熄灭；不会突然让角色坠落，站在平台上时先送回安全地面。
- **提示层级**：先靠实体导管显示两条去向；停滞后强调“一个输入、两个输出”；第二次复位后才在本地与远端目标上显示同形状的对应标记。

### Ch2 R2：断电窗口

- **视觉锚点**：未来侧过载站同时接向陆衡的门和对应墙面；过去侧同坐标是装甲供能机、通道警示灯和守卫，三者动作共享同一机械动机。
- **首次观察**：玩家可先在安全位置触发一次无敌人的短演示，看到陆衡门先开、过去侧警示灯后亮；守卫在演示完成后才进入警戒。
- **单人切换窗口**：触发信号前，星遥可站在危险通道出口旁的安全区；信号发出后不强迫切换，单人模式自动让另一侧维持防御与当前位置。
- **复位反馈**：激光先熄灭、守卫装甲恢复、陆衡门关闭、过载站最后卸压；明确播放“在途结果被取消”的回收声。
- **提示层级**：先让警示灯和装甲供能线自行说明关联；一次失败后提示“开路和危险来自同一信号”；再次失败才指出应先穿过通道，再等待装甲出现可见裂口。

### Ch2 R3：回传

- **视觉锚点**：未来侧压力板、守卫巡逻线和板后的固定挡块处于同一视野；过去侧对应守卫站在同坐标门前，死亡位置可被两侧共同读出。
- **首次观察**：星遥击杀前，陆衡可安全引导未来守卫经过压力板，看到板会下沉但不会锁住；这一步不产生失败。
- **单人切换窗口**：过去侧守卫进入最后受击状态时短暂停顿，给单人玩家切到陆衡；未来守卫的破防攻击在未操控时只预警，不结算伤害。
- **复位反馈**：若死亡抵达时守卫不在板上，残骸短暂显示后被相位回收，守卫在巡逻起点重建；过去侧已完成击杀不要求重复。
- **提示层级**：先展示压力板需要持续重量；第一次错位后强调“它会倒在抵达时的位置”；第二次错位后才在巡逻线上标出一个短暂的板区投影。

### Ch3 R1：时间走廊

- **视觉锚点**：三个不同长度的机械继电器与过去侧平台、门、气闸沿行进方向一一对齐；每个输出使用同形状端口标记，而不是数字文字墙。
- **首次观察**：星遥可先走一遍没有敌人的短预演，看到三处阻挡的空间顺序；随后回到起点，陆衡再配置继电器。
- **单人切换窗口**：每个输出抵达后都形成一个稳定落脚点；波次只在玩家主动越过对应地标时进入，避免切换角色时被连续夹击。
- **复位反馈**：只重置尚未通过的走廊段；平台送回安全地面、门和气闸复位、该段继电器弹回，前面已经完成的段落保持。
- **提示层级**：先用继电器机械长度和三处地标表达先后；停滞后提示“先排路线，再选延迟”；再次复位才显示一次从起点到终点的无文字抵达预演。

### Ch3 R2：双重条件

- **视觉锚点**：未来侧双联锁有两个独立机械臂；一个输入来自陆衡的配重板，另一个穿墙对应过去侧守卫板，最终共同指向升降台。
- **首次观察**：无敌人阶段允许玩家分别压下任一板，看到对应机械臂闭合而升降台不动；两个条件的关系在安全环境中成立。
- **单人切换窗口**：陆衡配重放稳后保持；星遥守卫死亡形成稳定残骸后保持。任何一边成立都不会因切换角色自动回退。
- **复位反馈**：错误只复位未成立的一侧；配重回到近处托架，守卫残骸回收并在战斗起点重建，机械臂逐个松开。
- **提示层级**：先看两个机械臂；一次停滞后提示“少一边都不会动作”；第二次错误后才分别点亮当前已满足和仍缺失的实体输入线。

### Ch3 R3：留住回声

- **视觉锚点**：未来侧三格蓄能器、机械棘爪和锁存门处于同一画面；过去侧三只寄生体沿路线分开出现，每只对应一格相同形状的窗口。
- **首次观察**：第一只寄生体死亡后，玩家能完整看到“在途—抵达—抬起一格—棘爪扣住”的无压力演示，第二只才开始主动攻击。
- **单人切换窗口**：每格蓄能完成后永久保持，敌人之间留出安全地带；无需在三只敌人之间连续快速切换。
- **复位反馈**：单只敌人失败只重置当前段；整房复位时棘爪从第三格到第一格依次释放，门最后关闭，确保玩家理解被清空的是累计状态。
- **提示层级**：先让格数与敌人数形成自然对应；停滞后提示“每次抵达只抬一格”；第二次复位后才高亮棘爪，说明已成立的格子不会自行回落。

## Ch4：相位猎手

进入 `chapter_04.tscn` 即进入 Boss 场。不存在 `ch4_r1`、`ch4_r2`、`ch4_r3` 或独立 `boss_checkpoint.tscn`。

### 第一阶段：拆甲

- Boss 位于未来侧。
- 星遥击杀过去侧对应体。
- 摧毁事件延迟抵达后逐片拆除未来 Boss 甲片。
- 陆衡负责存活和观察抵达时序，不进行前室谜题。

### 第二阶段：磁夹

- Boss 转入过去侧，星遥负责引位。
- 陆衡通过实体管线延迟触发磁夹。
- 磁夹必须有明确预警、抵达动画和失效恢复，不能靠 HUD 文本解释。

### 第三阶段：核心

- 陆衡打开短暂核心窗口。
- 星遥在过去侧完成终结。
- Boss 失败清空在途事件并返回菜单；继续游戏从第一阶段干净状态开始。

## Ch5：抵达

两侧时空因扰乱器短暂重合。冷色加固墙和暖色事故残骸出现在同一地点，两人才确认自己一直处在同一设施的不同时代。

必须留一人在过去稳定乱流。陆衡想留下，星遥最终强行把他送回未来，自己留在过去并失踪。

Dialogue Manager 提供一次同结局选择：

- “理解她的决定”
- “反抗，要求自己留下”

两个选项只改变陆衡的表达，最终都收束到星遥送他回未来。尾声让工厂底噪逐渐消失，以低音量菜单主题回归；画面熄灭前出现疑似来自星遥的新信号。

## 主页与连续音频

- 主页在入场动画完成后播放 authored `24s` 过去/未来循环：冷态保持 `8s`、慢变 `4s`、暖态保持 `8s`、慢变 `4s`；标题与按钮不随背景移动或变色。
- 低闪烁模式使用约 `28s` 的缓慢版本，不做层间位移；设置与感谢页打开时背景循环继续低幅运行。
- 四首 BGM 与工厂底噪均按 import loop 播放，并保留活动播放器自然结束后的重启兜底。
- story 对话暂停玩法，但音乐与环境播放器使用 `PROCESS_MODE_ALWAYS`，不因 Dialogue Manager 暂停而停止。

## Dialogue 节奏

- story balloon：章首、章末、关键剧情和 Ch5 选择；暂停游戏并等待玩家推进。
- radio balloon：靠近实体机制后的短句；不暂停并自动关闭。
- 两类 balloon 位于上下分屏中线；普通 story 只用小箭头提示点击或确认键推进，不显示“确认 / 继续”。
- 一个 title 是一次完整会话：只在第一行播放 `conversation_in`，行间原地更新并逐字显示，`END` 后才播放 `conversation_out`；不再一句一开关。
- 首次确认补全当前行，第二次确认推进；story 约 `0.032s/字`，radio 约 `0.024s/字`，非空白标点字符每两字最多播放一次低音量打字音。
- Ch1–Ch3 章首与首房对白合并，末房完成与章末对白合并；Ch4 章节与 Boss 入场对白合并。
- Ch1 到 Ch4 的章节切换使用中线合拢、标题和展开动画，总时长约 `1.4s`，不使用白闪。
- 标题使用 `chapter_XX_open`、`chapter_XX_complete`、`chX_rY_open`、`chX_rY_complete` 和语义化 bark 名称。
- 不使用常驻教程条、键位墙或 HUD 任务说明。

## 失败与复位

- 普通房：冻结输入、清空在途事件、重建当前房间，再恢复双方玩家。
- 解谜错误：使用房间复位或局部设备复位。
- Boss：失败后返回菜单，checkpoint 只保存 Boss 开始。
- Finale：无失败；退出或中断后从整段演出开头重播。

## 人工验收

- 新游戏模式选择、旧存档继续、单人切换和完整本地双人。
- P2 缺失等待、断线暂停、任意未占用手柄重连。
- 九个正式房间的因果链和复位。
- Ch2 全程 `1:1` 分屏；Ch3 星遥主视角布局。
- 实体模块拿取、旋转、插槽、描边和 radio bark。
- 舰载无人机、地行寄生体、设施守卫的预警、攻击、恢复和死亡。
- Boss 三阶段、失败 checkpoint 和完整 Ch5 演出。
