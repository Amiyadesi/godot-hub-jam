# ADR 0002: 退役 Phase Lag 原型

**状态：已接受**

## 背景

原型《迟相 / Phase Lag》依赖双角色、双空间、状态延迟传导、实体电路和三轮 Boss。多轮试玩和设计审查表明，这个结构在当前 Jam 容量内过度依赖说明文字和大规模 authored 内容，核心手感也没有先被验证。

## 决定

项目转向 Delay Trace：单一玩家移动、永久过去体和由 authored 记录器数量决定上限的短暂未来体。移除旧双空间玩法、章节、Boss、因果总线、旧关卡资源和相应 autoload。保留通用菜单、设置、感谢页、暂停、音频和最小存档框架。

不迁移旧开发存档；旧 schema 不属于发布承诺。旧素材目录若仍被通用菜单引用，可暂时保留为占位资源，但不得作为 Delay Trace 正式玩法或美术接口。

## 后果

- 现有旧存档和 Phase Lag 场景不应再被加载。
- 游戏入口在用户提供 Delay Trace 灰盒前保持禁用，避免自动生成替代关卡掩盖问题。
- 未来扩展只能在纯追逐与三时态灰盒分别通过试玩后进行。
- 旧项目快照保留在独立 Git commit，方便回溯，不作为当前实现基线。
