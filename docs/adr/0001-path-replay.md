# ADR 0001: 路径回放，而非输入重模拟

**状态：已接受**

## 背景

Delay Trace 的过去体和未来体都必须忠实呈现玩家已经走过的路线。玩家移动含土狼时间、跳跃缓冲、墙滑、冲刺调向、碰撞与传送；重新模拟输入会把当前关卡碰撞、帧率和后续调参带入旧历史，导致“过去”不再是已经发生的事实。

## 决定

每个 physics tick 记录一个 `TemporalFrame`：时间、位置、速度、朝向、动画名和离散标志。`TemporalTrack` 按时间采样位置：普通相邻帧允许插值，回传使用明确 `RECALL` 帧作为断点。

回传发生时，同一时间戳保留两帧：最后一帧正常位置以及标记为 `RECALL` 的回传目的地。采样在回传时刻之前保持原路径，恰好到达时刻才读取回传帧，绝不跨传送插值。

过去体和未来体是忽略地形的 `Area2D`，仅播放采样路径并承担时态碰撞合同。它们不重新运行玩家输入或 `CharacterBody2D` 物理。

## 后果

- 玩家能力或关卡碰撞之后改变，不会篡改已经录下的历史。
- 过去体/未来体的移动具有确定的、可单测的轨迹语义。
- 时态体不能自然继承地形碰撞、墙跳或新输入；这符合“重演已发生路径”的设计。
- 记录内必须显式保留所有影响可读性的离散事件，不能只存坐标。

## 验证

`Tests/DelayTrace/run_tests.gd` 覆盖普通插值和回传断点。任何改动若重新引入“跨回传插值”或输入重模拟，应先更新本 ADR 并重新审查时态规则。
