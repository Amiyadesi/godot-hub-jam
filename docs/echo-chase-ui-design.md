# 《回声追猎》UI 视觉规范

## 方向

- UI 属于地图的注释层，不是覆盖世界的卡片系统。
- UI 框架只使用黑、白、灰阶；三时态机制演示与玩法反馈可使用洋红、青白、琥珀三色，但不能扩散为普通装饰色。
- 参考 `Minit`、`Gato Roboto` 与 `Return of the Obra Dinn` 的高对比、低层级和像素纹理处理，不复制具体布局或素材。
- 使用 Fusion Pixel Font 简体中文比例字宽版本。

## 信息规则

- 页面只保留标题、命令、设置名称、当前值和必要确认文本。
- 禁止技术标、英文副标题、状态装饰文案、说明小字和常驻操作提示。
- 需要解释的内容由玩家作者后续决定是否加入；默认不替作者补文案。

## 组件规则

- 普通按钮无底框；hover、键盘焦点和手柄焦点统一为白底黑字反色。
- 按下态仅改变反色深浅和纵向内容边距，不缩放、不旋转、不发光。
- 导航用细线、方形节点和文字构成；禁止圆角矩形菜单卡。
- 设置页使用左侧窄导航与右侧账本行。每个完整设置行以下方横线分隔，不使用中央竖线或短连接线。开关显示 `[ ON ] / [ OFF ]`，focus/hover/pressed 只有短下划线，松开后才提交文本状态；滑杆使用细线轨道。
- 确认弹窗允许一个小型硬边框，因为它需要阻断输入；禁止嵌套卡片和大面积装饰。
- Toast 使用左侧粗线的小型角标，不占据视野中央；根节点及全部后代必须 `MOUSE_FILTER_IGNORE`，确认弹窗仍负责阻断输入。

## 动态规则

- 主菜单地图根据鼠标位置向反方向平滑移动，最大偏移约 `16×10px`。
- 背景四周额外扩展 `32px`，任何鼠标位置都不得露出黑边。
- 主菜单严格划分三个等宽区域，剪影中心位于 `1/6、1/2、5/6` 屏宽和 `54%` 屏高。角色层不参与鼠标视差。
- `1.8s` 入场同时编排标题裁切插入、按钮自下而上排列，以及“过去→现在→未来”依次实体化；任意离散输入可直接落到最终帧，但不能顺带触发按钮。
- 入场后三个剪影只播放 `idle` 和 `±6px` 漂浮，周期 `2.4s`，彼此错开 `0.8s`；不再绘制轨迹或播放跑动循环。
- 新游戏从现在体位置扩张青白圆形，Continue 从过去体位置扩张洋红圆形。遮罩满屏后切场景，再以同色 `0.35s` 淡出；玩法世界在淡出期间冻结且不累计过去延迟。
- 低闪烁模式取消亮白爆心和密集粒子，径向扩张由 `0.65s` 放慢到 `0.9s`。
- UI 内容层不跟随背景移动。

## 页面结构

- 主菜单：地图背景、三个等宽固定时态剪影、标题，以及右下的开始/继续/设置/感谢/退出路线节点。
- 设置：左侧通用/按键导航，右侧设置行，底部返回与感谢。
- 感谢：标题、资源列表、返回。
- 暂停：左侧命令列，右侧保留压暗后的玩法画面。
- 键位：左侧动作名、右侧当前绑定、整行下方分隔线；捕获弹窗只显示动作名和输入请求。

## 分辨率

- 设计基准为 `1920×1080`。
- 仅支持同为 `16:9` 的缩放验收，包括 `1280×720`。
- 不为超宽屏或非同比例窗口增加专用布局，也不批量生成截图。
